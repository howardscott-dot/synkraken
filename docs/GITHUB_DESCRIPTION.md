# GitHub Description

## Short Description

Open-source AI Workforce Operating System for coordinating, governing, tracing
and operating teams of AI agents.

## Longer Description

SynKraken is a local-first control plane for heterogeneous AI workers. It
provides runtime discovery, workforce health, proposal governance, rooms,
flight recorder replay, incident recovery, memory governance and a spatial
desktop console.
