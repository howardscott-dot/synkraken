# Category Position

## Category

SynKraken is an **open-source control plane for AI workforces**.

This category is deliberately narrower than "agent platform" and broader than
"chat UI." SynKraken manages the work around multiple runtimes: visibility,
governance, coordination, memory, recovery, and observability.

## Category Language

Use:

- control plane
- AI workforce
- local-first
- runtime-neutral
- management harness
- governance layer
- memory layer
- coordination system
- observability layer

Avoid using "bridge" as the primary product position. The bridge skill and
adapter layer are implementation details; the product category is control
plane.

## Differentiation

SynKraken is not:

- another coding agent
- an orchestration LLM
- a chatbot
- a CrewAI clone
- a hidden autonomous swarm

SynKraken should not present itself as a model, agent brain, automatic company,
or remote orchestration SaaS.

## Short Descriptions

Canonical one-liner:

> Open-source control plane for AI workforces.

Longer description:

> SynKraken is a local-first, runtime-neutral control plane for AI workforces:
> a management, governance, memory, coordination, recovery, and observability
> layer around the AI runtimes users already choose and pay for.

## Ownership Split

Users own subscriptions, API keys, costs, and runtimes.

SynKraken owns visibility, governance, coordination, and recovery.
