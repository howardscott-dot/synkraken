# Why SynKraken

SynKraken exists because AI work is outgrowing isolated chats.

Operators now run multiple AI tools: coding agents, terminal CLIs, local model
servers, review bots, and research assistants. The hard problem is no longer
only "can an AI answer this prompt?" The hard problem is "how do I operate a
team of unreliable but useful AI workers without losing visibility, authority,
or evidence?"

## One-Agent Chat

One-agent chat is fast and flexible. It is also ephemeral. It rarely gives the
operator durable rooms, replayable traces, approval ledgers, runtime health, or
recovery controls.

SynKraken keeps conversation visible but adds persistent operational state.

## IDE Copilots

IDE copilots help with coding inside an editor. They do not manage a mixed
workforce of external runtimes, room transcripts, proposal approvals,
incidents, handoffs, or cross-runtime trust.

SynKraken is not an IDE. It is the control plane around the workers.

## Terminal Multiplexers

Terminal multiplexers can show many shells. They do not know what a worker is,
what a proposal is, whether a delivery failed, which runtime is degrading, or
how to replay a trace.

SynKraken records those facts as operational data.

## Workflow Automation

Workflow tools run predeclared steps. AI work is messier: outputs vary, some
workers are weak, failures need inspection, and sensitive actions need
approval. SynKraken focuses on operator-supervised coordination rather than
hidden autonomous execution.

## Agent Frameworks

Agent frameworks help developers build agent workflows. SynKraken is not a
library for embedding in an app. It is an operator-facing system for managing
AI workers and the state around their work.

## The SynKraken Difference

SynKraken brings together:

- workforce governance
- runtime reputation
- traceability
- human approval
- incident recovery
- spatial operations
- persistent rooms
- bounded goals, decisions, handoffs, proposals, and memory

The result is not a smarter chatbot. It is an operating system for local AI
work.
